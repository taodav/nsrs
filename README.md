# Novelty Search in Representational Space for Sample Efficient Exploration
Code for the paper [Novelty Search in Representational Space for Sample Efficient Exploration](https://arxiv.org/abs/2009.13579) presented at NeurIPS 2020.

Originally based on the [DeeR codebase](https://github.com/VinF/deer).

## Visualising 20241120 experiment results

A helper script was added under `scripts/plot_20241120.py` to reproduce the bar chart with standard-deviation error bars reported in the paper. 运行方法（Windows PowerShell）：

```powershell
python scripts/plot_20241120.py
```

生成的图像将保存到 `figures/20241120_results.png`.
